# Sample / placeholder outputs

SVG charts in this directory (`throughput.svg`, `latency.svg`, `scale.svg`, `ffi.svg`) and `summary.json` are generated by:

```bash
python scripts/bench-charts.py          # from summary.json
make bench                              # full run → summarize → charts
```

Until you run `make bench` on your machine, numbers may be illustrative placeholders — replace by re-running the suite. See [../README.md](../README.md).
